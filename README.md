# Bob MTB Performance

Personligt MTB-dashboard (første prototype) med tre ture fra samtalen.

## Lokal udvikling

```bash
npm install
npm run dev
```

## Vercel

Importer GitHub-repository i Vercel. Framework preset: Vite. Build command: `npm run build`. Output directory: `dist`.

## Vigtigt

Dette er en **demo**. Strava er **ikke** forbundet, og data opdateres ikke automatisk. Næste fase er sikker Strava OAuth, server-side tokenopbevaring og database. Læg aldrig Strava client secret i frontend-kode eller GitHub.
